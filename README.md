# 链上小课堂

用积木、指纹和链子，把区块链讲给 8–12 岁的小朋友听。

这是一份纯静态的单页课程：六个概念、一个可以动手改的区块链演示。
没有构建步骤，没有后端，也不依赖任何第三方库。

## 运行

### 直接打开

双击 `index.html`，或用浏览器打开它即可。

演示里的「指纹」由普通 JavaScript 计算，不依赖 Web Crypto，所以
`file://` 协议下也能正常玩。

### 本地服务器（推荐）

```bash
# 在仓库根目录执行
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

用 Node.js 也可以：

```bash
npx serve .
```

### 部署

把仓库根目录的静态文件原样上传到任意静态托管即可，不需要打包：

- GitHub Pages
- Netlify / Vercel / Cloudflare Pages
- Nginx、Apache 或对象存储

唯一的要求是让 `index.html` 位于站点根路径，并保留 `css/`、`js/`
的相对目录结构。


页面只引用三个本地资源：`css/style.css`、`css/demo.css` 和
`js/demo.js`。没有图片、字体或外部 CDN 依赖。

## 页面内容

### 1. 首屏（`#top`）

课程标题、一句话介绍，以及两个入口：

- 「从第一个概念开始」→ 跳到六个概念
- 「先去玩一下」→ 跳到互动演示

### 2. 六个概念（`#concepts`）

沿着六站走完一条链，每一站只讲一件事：

| 站点 | 锚点 | 讲什么 |
| --- | --- | --- |
| 01 | `#concept-what` | 什么是区块链：大家一起记、一起对的账本 |
| 02 | `#concept-block` | 区块：装一段时间记录的盒子 |
| 03 | `#concept-hash` | 哈希：内容算出来的独一无二的指纹 |
| 04 | `#concept-chain` | 链条：每块都记着前一块的指纹 |
| 05 | `#concept-decentralized` | 去中心化：没有老大，人人手里一本账 |
| 06 | `#concept-consensus` | 共识：大家一起核对，新块才接得上 |

每站都配有示意图、比喻和一句「记住」小结，预计完整阅读约 15 分钟。

### 3. 互动演示（`#demo`）

见下一节。

### 4. 页脚

重复提供「六个概念」「动手演示」「回到顶部」三个页内入口，
并注明课程只用比喻，不涉及炒币或真实资金。

## 演示怎么玩

演示区由 `js/demo.js` 在页面加载时生成，默认已经有「创世区块」和
一个示例区块。

1. **添加区块**：在「下一个区块记什么？」输入框里写一句话
   （最多 30 个字符），点「＋ 添加区块」，或直接按回车。
   不填内容时会自动使用示例文案。
2. **观察指纹**：每个区块都会显示「本块指纹」和「前一块指纹」。
   新区块会记住前一块在记账时写下的指纹。
3. **制造篡改**：直接修改任意区块的「记录的内容」（最多 40 个字符）。
   该区块的指纹会立刻变化，卡片变成「警报」，它后面的所有区块
   也会跟着对不上，顶部状态栏会指出第一处断链。
4. **自动修复**：把内容改回原样，整条链会自己恢复「完好」。
5. **重新开始**：点「重新开始」清空并重新生成默认的两个区块。
6. **上限**：最多 12 个区块，到上限后「添加区块」按钮会禁用。

演示只在当前页面内存中运行，刷新即重置，不会保存或上传任何内容。

### 关于「指纹」

演示使用 FNV-1a 拼出的 16 位十六进制字符串，是一个便于离线运行的
**简化版指纹**，不是密码学哈希。真实区块链使用 SHA-256 这类算法，
并由许多节点共同记账；页面中的提示文案也向小朋友说明了这一点。

## 无障碍与兼容性

- 提供「跳到主要内容」链接、语义化标题层级和页内导航。
- 演示状态使用 `role="status"` + `aria-live="polite"` 播报。
- 尊重 `prefers-reduced-motion`，减少滚动动画。
- 禁用 JavaScript 时显示 `<noscript>` 说明，六个概念仍可正常阅读。
- 布局为响应式，支持手机、平板和桌面。

## 冒烟检查

改动页面后，可以快速确认资源引用与页内锚点没有失效：

```bash
# 三个本地资源是否都存在
test -f index.html
test -f css/style.css
test -f css/demo.css
test -f js/demo.js

# 页面是否仍引用演示脚本
rg -q 'demo.js' index.html

# 起一个本地服务器，逐个访问确认返回 200
python3 -m http.server 8000
```

也可以直接用浏览器打开页面，检查：

- 六个概念和示意图正常显示；
- 演示区出现两个默认区块；
- 添加区块、修改内容、重新开始都能工作；
- 浏览器控制台没有报错。
